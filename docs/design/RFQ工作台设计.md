# RFQ 工作台设计

核对日期：2026-11-05。场景是供应商接到客户询价后准备报价，UI 围绕一份询价反复核对；官方产品参考仅用于信息架构借鉴。

## 外部参考与适用边界

- [Odoo 19 Requests for quotation](https://www.odoo.com/documentation/19.0/applications/inventory_and_mrp/purchase/manage_deals/rfq.html)：借鉴询价对象、供应商价格/交期、行项目和状态分离。已从官方搜索结果取得流程摘要；正文读取超时，未作像素或截图复刻。
- [SAP Issuing RFQs and Obtaining Quotations](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/af9ef57f504840d2b81be8667206d485/797eb65334e6b54ce10000000a174cb4.html?locale=en-us)：借鉴询价、收到报价和后续活动分别有状态。官方搜索摘要已核对，动态正文未取得。

两者偏采购方发起 RFQ，本项目是接收询价的报价方；不照搬确认采购订单或自动发供应商邮件的流程。调研通过 agent-reach 的 Jina Reader 路径尝试，超时后用 web 官方来源查询补充。

## 信息架构

采用单列连续对话：顶部一行切换询价，中间逐轮消息和内嵌产物，底部常驻输入。旧三列布局及长能力介绍已撤下。保留暖灰、深色导航及现有信号色，动效仅用于执行反馈；不添加装饰图片。

- 询价：顶部下拉选择，显示行数与待核对数；执行时禁止切换。
- 对话：按任务保存用户与助手轮次。起始提供生成草稿/检查缺口快捷操作；后续可直接追问。Enter 发送、Shift+Enter 换行，中文输入法确认不误发。
- 执行：请求运行中显示等待状态并保留停止按钮。当前 API 非流式，完成后批量展示真实工具回执，不能宣称实时步骤。
- 产物：每轮内嵌可展开草稿表格，长表在卡片内滚动；工具与来源默认折叠。不重复放置侧栏。
- 人工核对：只允许前往工作台逐行检查，不在 Agent 页清除全部风险，不直接写入单价或导出。

主对话区独立滚动，输入框始终可见；小屏缩减外壳导航占用，草稿表格只在卡片内横滚。无图片槽位，不需图片生成。

## 本次实现与边界

已在 `app/src/pages/AgentPage.tsx` 接入 `POST /api/agent/run`，使用 AbortController 停止等待，并丢弃旧请求的迟到结果；询价或策略改变后标记旧记录失效。后续普通消息不改变业务 basis；发送给模型的 history 只包含同任务且同业务 basis 的最近六条公开对话，每条最多2000字符，总计最多12000。旧业务记录可见但不进入新上下文。会话单独使用 `rfq-chat-v1`，不将旧版一键批准状态当成新 Agent 审批。

本次不迁移工作台业务规则，原有单位、件状、证书、供应商和最终导出仍需在那里核验。后端收到的是真正已解析行，不宣称在本页重新读完全部邮件附件。费用/token 暂未统计，页面明确说明。

接口失败时保留错误并可重试；空任务引导用户导入。停止不保证第三方模型服务已取消，但不会采用迟到结果。运行结果不写入价格或风险集合，用户进入工作台后仍需自行确认。

## 验收

构建通过是编译证据；浏览器核对由 supervisor 统一进行。应核对：有成本/缺成本两类行、分析模式无价格、运行中停止、运行期间输入改变、队列切换、窄屏和键盘焦点。旧版 `verify-agent-lifecycle.mjs` 测试一键批准流程，不再代表新预审组件的验收。


## 2026-11-05 页面视觉整改

询价任务、异常巡检、库存与成本统一为浅色导航、灰白内容底、石墨色主文字和少量橙色主操作。统计信息改为紧凑横栏，不再用大卡片挤占列表空间；风险通过状态标签显示，列表保留中性背景。

模型与报价设置入口固定在左侧底部，替换原右上角入口，打开同一个设置弹窗。业务功能和模型配置内容保持原实现。

询价任务增加编号/客户搜索与全部、待核对、可报价筛选。任务与风险表每页20条，筛选变化后回到第一页；状态、来源及操作文字禁止竖向换行，长任务名省略并保留原完整标题。表头固定，表格内部滚动，分页栏独立显示。

异常巡检使用一排可点击的分类与计数，增加物料/询价搜索；风险原因采用已有中文解释。行唯一标识使用任务、物料行key、风险类型，避免同件号多行导致列表key重复。

库存表每页20条，件号列固定；优先显示描述、库存、单位与近采价，扩展字段横向滚动查看。SQL和JSON实现说明移出业务页面，自定义字段录入收纳到折叠入口。输入保存逻辑不变。

浏览器已验证：左下角设置可打开与关闭、任务翻页后搜索重置页码、零风险分类空态、库存翻页。未修改模型或库存数据进行视觉验收。

## 全局助手入口

询价列表、异常巡检、库存页与询价详情均保留右下角报价助手入口。浮窗跟随最近打开的询价，不展示独立任务编号或关联询价选择器；切换任务在主列表完成。尚未打开任务时仅保留“打开询价”和“上传询价”操作，不默认处理第一份询价。

浮窗采用380px宽、最高520px的紧凑尺寸。只保留标题、两项快捷操作、消息与输入框；移除上下文副标题、重复欢迎语、重复头像及底部使用说明。侧栏移除数据引擎就绪与能力评测文字，库存页移除重复条目数和连接状态。

## 统一浮窗与放大对话

取消独立“专注对话”入口。放大/恢复只改变展示尺寸，始终使用同一个对话组件、同一任务会话和输入草稿。放大后不再显示旧版询价队列、重复上传入口或询价选择器。

界面取消独占一行的询价编号；任务与行范围继续在内部隔离。主列表负责选择任务，物料行“问助手”负责行级范围。结果卡保留实际物料、价格与依据，接受价格时仍核对所属行。
