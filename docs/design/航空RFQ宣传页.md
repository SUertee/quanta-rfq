# 航空 RFQ 宣传页

更新：2026-11-07。适用页面：`app/public/quanta.html`。

## 定位与信息结构

面向航空航材询价与报价场景，延续深蓝 / 青色、圆角顶栏和光晕首屏。首屏明确“航空航材 RFQ”，六个阶段入口跳到同一功能演示并选中对应阶段。顶部“功能 / 流程”均为页内定位，右侧“打开工作台”进入应用。

原来 306vh 的文字滚动区域由功能界面替代。演示以同一份两行询价贯穿六阶段，不展示虚构的提效比例、客户背书或自动批准能力。

| 环节 | 可见结果与操作 |
| --- | --- |
| 接收询价 | 邮件文件与 Excel 样例原件；切换查看内容，不宣称已连接邮箱 |
| 提取需求 | 件号、描述、数量、件状、证书与交期表；筛选缺失字段 |
| 查询依据 | 内部库存和成本匹配及来源；无可用依据的行保持空值 |
| 检查条件 | 通过与待补充条目；按待处理筛选 |
| 报价草稿 | 调整成本加价率并更新建议单价、行金额与合计 |
| 确认导出 | 明确审核有价行、确认无依据行本次不报后，下载客户 HTML 与内部 CSV |

所有数据明确标为“交互演示 · 示例数据”。它是独立的前端功能预览，不调用模型、不读取实际库存，也不写入业务记录。真实操作通过“进入工作台”完成。客户演示文件不含内部成本，内部依据文件保留样例成本、来源与排除原因；修改加价率会重新要求审核。

## 图像

底部原集装箱船图替换为无航空公司标识的客机起飞画面。图像由内置 imagegen 于 2026-11-07 生成，并转换为 JPEG，约 225KB。项目资产：`app/public/images/aviation-takeoff.jpg`。不代表特定航空公司、飞机制造商或真实机场背书；图片 alt 标明 AI 生成示意图。原始生成文件留在本机生成目录，网页使用项目内资产，不依赖外部图片代理。

底部图文区保持深色分栏构图，并展示六环节简洁流程。分栏最小高度改为 760px，窄屏图片区单独成行，减少高竖屏下飞机主体被过度裁切。

## 实现与验证

- 展示脚本、样式分别为 `landing-features.js`、`landing-features.css`，路径相对宣传页，适配 `/quanta-rfq/` 部署。
- 生产静态服务补充 JPEG MIME 类型，测试检查线上等价服务返回 `image/jpeg` 与有效 JPEG 文件头。
- Happy DOM 验证六阶段、原件预览、筛选、改价、未报价行、审核与跳过的导出门禁、客户 / 内部内容分离及改价后失效。
- 宣传页旧滚动脚本移除对已删除介绍区域的依赖，使用模拟 Canvas 的 DOM smoke check 验证启动与滚动事件无空节点错误。
- 浏览器连接仍超时，未取得真实浏览器截图，不将 DOM 验证当作像素排版与真实下载对话框验收。
