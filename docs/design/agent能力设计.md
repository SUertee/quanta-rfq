# RFQ Agent 能力设计

现行核对日期：2026-11-07。工程为 merged-workbench，Agent `rfq-quote` 版本1.1.0。本文分开记录当前实现、范围外目标和本例验证；历史演进见 [归档](../archive/2026-11-07-agent能力设计-迭代记录.md)。

## 背景与产物

围绕 RFQ 六阶段：接收询价、提取需求、查询依据、检查条件、形成草稿、确认导出。素材为航空备件演示询价，不能称为真实客户生产数据。Agent 产出待核对的报价建议、来源与缺口，不自动批准、不修改库存、不代签或发送客户消息。

六阶段是业务闭环，不是模型工具数量。上传与解析、证据查询、人工审核和导出由业务服务与 UI 配合完成；不能说 Agent 已自主包办全部六阶段。

## 已实现的最小工具循环

使用 LangChain `createAgent`，基于 LangGraph 运行时；Node.js ≥22。工具与 prompt 分别见 `app/server/agent.mjs` 和 `agent-prompt.mjs`。

| 实际注册工具 | 当前职责 | 约束 |
| --- | --- | --- |
| read_inquiry | 读取本请求已解析的询价行与委托 | 不直接解析原始 PDF／邮件附件 |
| lookup_costs | 精确件号查询服务端内部成本 | 不联网估价、不比较供应商，不接受客户端成本作为权威 |
| build_quote_draft | 确定性计算或仅分析 | 无成本、多重成本、非人民币、单位/件状冲突、库存不足不出建议价；仅分析无建议价 |

工具按 read → lookup → build 代码门禁执行。缺工具结果不虚构成功；最终公开摘要由工具产物确定性组织，不返回模型原始自由文本或思考。模型委托和材料文字不能授权修改审批或越权读取。

带 `inquiryId` 的业务请求通过 `resolveAgentScope` 校验请求 keys 属于该询价，拒绝重复与跨询价 keys，只用数据库中的件号、数量、单位和件状，不把单行范围扩大成整单。兼容 batchId 旧名称不等于建立第二个业务主体。

## 定价与人工操作

现行设置是成本加价率：`成本 × (1 + markupRate)`，不是目标毛利率。例如14.37×1.25→17.96，售价毛利约20%。服务器兼容显式 `marginRate`（成本÷(1−毛利率)）不代表当前设置切换口径；两种术语不能混用。

加急与批量参数仍须按实际 policy 明示；当前实现存在默认参数，不能宣称已实现有版本的企业策略服务。精确库存足以满足需求时，不因供应商候选 MOQ 扩大客户出货数量。

用户可明确接受 Agent 建议单价，但接受价格不自动核销业务风险。关键材料、物料或定价策略变化后，相关价格和核对需重新校验。人完成核对后才允许导出；导出先等待服务端审核快照成功，失败不生成下载文件并提示原因。

## 对话、模型与运行状态

前端使用 `/api/agent/run`，本机模型配置由服务端读取 `app/.env.local`，旧工作台 UI 的模型设置不切换这条 Agent 配置。对话历史最多12条 user/assistant、单条2000字符、总长12000，历史是背景而非授权。

仅分析指令由代码约束；可保留有效成本证据，但不出建议价。请求使用 AbortSignal，取消后迟到结果不应用；服务端断连或90秒超时取消。本地运行审计持久化不等于 LangGraph checkpoint；尚无完整模型过程恢复、多用户权限或生产调度保障。

## 同库审计

`agent_registry` 保存 agent_id/version、prompt指纹和工具清单；`agent_runs` 保存运行、模型、actor、时间、受限输入/结果摘要与指纹；`agent_events` 保存按序工具 started/done/failed 等事件。版本与事件不可改删，终态运行不可更新，由 SQL trigger 保证应用内约束。

`agent_runs.inquiry_id` 与 `quote_snapshot.inquiry_id` 是逻辑关联，无数据库 FK。quote_snapshot无run_id外键，不把两者称为强制闭环追踪。成本 fingerprint 不包含完整原始成本快照，不能完整重放历史；本地管理员可操作数据库，不声称合规防篡改。

## 本例验证与范围

2026-11-07 使用一份一行合成CSV，真实 DeepSeek-V4.1-Flash 按3工具形成17.96建议价，人接受价格并核对后导出客户HTML和内部CSV，数量10、合计179.60，服务端快照与文件一致；运行与6条事件持久化。详细环境、原件哈希、回执和截图见 [星宫验收报告](</Users/suerte/Obsidian/星宫/事业/竞赛/黑客松/2026/MatrixNEXT 2026 AI BUILDER FESTIVAL/04-开发实施/UI与Agent验收报告.md>)，工程原件见 `docs/verification/2026-11-07/`。

服务器重启后运行及6条事件仍可回读，页面刷新后已导出状态以当前内容哈希匹配服务端快照3恢复。人工核对与价格仍为localStorage配合review_log，不是跨设备企业审批。

本例通过不表示所有 PDF／OCR、供应商筛选、证书、交期或复杂规则已验收。未连接邮箱，不自动外发。目标六工具、三项业务 Skill 是后续设计，见 [工具与 Skill 设计](agent工具与Skill设计.md)，不要将其当作当前 registry 已注册工具。
