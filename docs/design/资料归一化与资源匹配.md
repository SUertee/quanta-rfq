# 资料归一化与资源匹配

## 范围与实现日期

2026 年 11 月 7 日，第一批增量改造覆盖资料类型字段、标准物料行、候选条件检查和 Agent 证据一致性。业务场景为航空备件 RFQ。完整六阶段与既有工作台结合，后续批次继续完善供应商资料入库、选用依据、证书交期规则及统一确认。

## 资料分类

`source` 保存来源渠道，`file_type` 保存文件格式，`document_type` 保存业务资料类型。资料类型支持 `customer_inquiry`、`supplier_quote`、`inventory`、`certificate`、`unknown`。

新建询价接口中的材料默认属于客户询价；历史文件类型标记为 unknown。当前前端上传入口仍是询价入口，尚未提供分类管理界面。调用接口显式上传其他类型时保存原件并提示单独处理，不能将其当成已经导入资源库。邮件附件沿用本次询价用途，混合用途附件的独立分类属于后续工作。

一次创建由 request_id 进行幂等关联，文件用 inquiry_id 关联询价，parent_id 保存邮件附件关系。此次没有新增按时间猜测关联关系的逻辑。向既有询价多次补充上传仍待实现。

## 标准字段与原始值

服务端 normalization.mjs 统一处理完整件号、数量、单位、件状和日期校验。件号仅处理首尾空白与大小写，保留所有后缀。Each 和 EA 等确认过的单位表达统一为 EA，FN 与 NE 保持区分。日期含糊或日历日期无效时进入待确认。数量只接受明确的十进制与标准逗号千分位；1,5、1e3、1 000 及小数点后恰为三位且可能表示千分位的文本暂不推断，保留待确认。

物料行 fields 中保留 rawFields、fieldSources、normalizationVersion。fieldSources 记录字段来源片段、位置和提取方式。人工修改记录操作者和手工值，contentId 为空，originalContentId 只用于关联原先的材料。修改前版本进入 line_revision。

历史数据缺少真实原值时，rawFields 保留空对象并标记 legacy_unknown，不能把迁移前当前值冒充原始提取值。迁移改变字段或问题列表时保存修订并提升版本；迁移编号 normalization-v1 保证不反复改写物料。

## 检索与候选检查

库存和价格资源保存 normalized_part_number，统一由同一个 JS 函数生成，建立索引。库存 API 写入时同步索引字段；直接使用外部 SQL 修改核心件号后，需要重启完成索引回填。

按完整标准件号查询，保留多条候选。resource-match.mjs 检查物料身份、单位、件状、数量、币种和价格。供应商记录另外检查 MOQ、生效日期、有效期、税基和来源授权。日期按 Asia/Shanghai 业务日期检查。

检查分别返回 pass、conflict、unknown。候选汇总为 usable、conflict 或 needs_review。当前证书、交期和附加要求仅保守标记为待人工确认；供应商种子数据缺少单位、授权或税基时，不能自动判定可用。

证据 snapshot 保留取得时的资源和检查。接口 current_match 另行返回对当前需求及日期的检查，不能覆盖历史快照。重新查询时旧证据进入 evidence_history。

## Agent 与审计

rfq-quote 版本 1.2.0 延用三工具循环。持久询价请求只采用服务端物料，读取内部库存与供应商候选。供应商候选本批用于解释缺口，价格仍按内部成本规则生成。

同一条持久询价中，内部成本定价与候选采用相同证据快照。缺失快照不会回退到另一份实时成本。候选返回 evidenceId、资源标识、检查和快照指纹，减少发送给模型的内容。

agent_runs.resource_snapshot 原子保存本次运行涉及的资源快照白名单，过滤自定义 extra 等任意字段。输入和成本指纹涵盖资源输入。历史运行保留原先审计内容，完整历史重放与企业策略版本仍待完善。

## 界面规范

沿用现有尺寸、颜色、圆角和按钮规范。原文旁仅展示有变化的字段，人工修改显式标记。候选直接显示条件满足、条件冲突或待确认及原因，不新增折叠和下拉。

## 验证与后续边界

新增回归覆盖原值保存、大小写与单位归一、完整后缀、日期、候选门禁、重复请求、乐观锁、迁移幂等和资源审计。浏览器本地实测使用合成文本，an3-5a、Each、fn 分别形成 AN3-5A、EA、FN，并展示内部库存和供应商候选。

后续批次需要完成独立资料分类界面、供应商资料提取入库、多次补充上传、字段冲突合并、选择供应商候选定价、证书及交期逐项规则、OCR 接通和端到端确认版本。当前实现不能作为这些能力已经验收的依据。
