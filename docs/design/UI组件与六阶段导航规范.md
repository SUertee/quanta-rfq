## 呈现原则

- 功能用上传框、文件条目、可编辑表格、下拉框、筛选按钮、开关、结果卡及下载按钮表达。删除“系统可以做什么”“如何使用本页面”等静态介绍，不用隐藏文字冒充交互。
- 保留字段名称、单位、真实状态、数据来源、缺失原因、解析失败、版本过期、未保存提示及删除确认。业务材料原文与 Agent 对本次问题的回答属于内容，不作为无用介绍删除。
- 统计若可筛选就做成按钮；配置规则若能试算就提供输入和结果；暂无数据时给有效操作，不提供空口的功能说明。尚未实现的能力显示明确待处理状态，不造成功回执。
- 全局导航用于切换询价、异常巡检、库存与成本；六阶段导航只属于当前询价。默认收起助手，保留右下角入口和物料行的上下文操作；打开助手后仍使用当前询价上下文。

## 六个阶段与实际元素

| 阶段 | 主区域 | 操作 |
| --- | --- | --- |
| 1 接收询价 | 文件名称、格式、读取状态、接收人/时间；历史任务展示可用原文 | 下载原件、进入物料核对；新询价仍由任务列表上传入口创建 |
| 2 提取需求 | 可修改物料表、缺失字段、原文问题、筛选与搜索 | 修改/新增物料、查看报价依据 |
| 3 查询依据 | 物料选择、原文位置、库存与成本字段、供应商候选 | 展开原文、刷新依据、进入条件检查 |
| 4 检查条件 | 待核对/全部筛选、逐行冲突与人工核对状态 | 查看物料、问助手、标记或撤销人工核对 |
| 5 报价草稿 | 草稿表、确认单价、计算结果、报价版式 | 按既有规则填建议价、修改单价、进入审核导出 |
| 6 确认导出 | 物料、人工核对、定价三组实际数量及阻断项 | 返回对应问题阶段、下载内部核价表/客户报价单 |

当前阶段标题及操作位于整行上方，下方为纵向六节点步骤栏与实际内容并排。节点采用连接线和序号，当前节点深色高亮；真实完成的非当前阶段显示勾选，待处理使用警示边框。名称与实际状态通过悬停或键盘聚焦查看，Escape收起。点击仍只切换面板，不改变完成状态。此约定按2026-11-07用户反馈取代早期无连线小圆点方案。

## 状态实现

阶段推导见 `app/src/engine/workflow.ts`。展示状态与选中阶段分开：stage 仅控制可见面板，inquiryStages 根据材料、需求缺口、依据、人工核对、有效单价和导出回执计算。

- 接收以存在的材料为依据，提取以实际物料和缺口为依据。
- 有库存/供应商记录只代表查询有结果，不能据此把条件检查标为通过。
- 条件阶段统计人工已核对行；没有规则报警也不自动视为人工审核完成。
- 草稿阶段统计实际填入有效单价的行；可导出与已生成导出文件是不同状态。
- 导出按钮继续受原有业务门禁约束，并要求全部有效报价行已人工核对、提取缺口已处理。修改物料会撤销该行已有确认和单价；生成建议价不自动标记核对。

这是 UI 与现有操作的连接，不代表服务端已经实现持久的六阶段状态机、全部专业校验或自动报价闭环。跨进程审批版本、异常恢复和业务规则的完整验收仍以实际后端结果为准。

## 全局整改范围

- 任务列表：可点击的全部/待核对/待核价统计，保留搜索、状态和创建入口。
- 库存：全部物料与零库存筛选、数据库连接状态、可编辑单元格、导入/新增/扩展字段。
- 异常巡检：沿用实际类型筛选、搜索、问题原因和任务跳转，问题原因不是功能介绍。
- 设置：移除静态教程；使用模型读取/测试按钮、开关、汇率与单位换算表；新增基础加价试算输入和实时输出。保留数据来源及未保存状态。
- 导入映射：源列、样例值、目标字段选择；新增“记住此映射”开关，控制映射是否保存；缺少必需列或重复映射继续阻止导入。
- 助手：保留实际结果、来源和必要限制；空草稿用生成按钮，避免介绍段落。
- 能力评测：用标注文件导入、模板下载和运行按钮替代开发说明。导入仅用于本次浏览器会话，指标只在实际运行后展示。
