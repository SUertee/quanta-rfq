# 工作台与嵌入式助手合并说明

日期：2026-11-05；合并目录 `版本对比/merged-workbench`，分支 `merged-workbench`。来源是 `current-chat` 当时的工作区改动与 `latest-team-20261105/app` 原始解压源码。两个来源均未覆盖，也未自动提交。

## 保留与取舍

- 最新工作台：异常巡检、任务耗时与操作统计、历史快照、重新核价、手工价格保护、暂不报价及客户版待报价清单。
- 最新业务配置：加急溢价、批量折扣、多币种汇率、最低运费与免运费门槛、导入映射与行业配置。
- 当前 Agent：服务端 createAgent、连续对话、整单/行级隔离、取消与迟到保护、嵌入右侧助手及右下角入口。
- 旧工作流 Agent 页面被连续对话助手替代。接受建议单价仅修改当前行价格并记为用户确认价，不自动核销风险。
- 暂不报价的行从 Agent 输入、工作台金额、毛利和客户报价主表排除；客户导出仍按原设计列入待报价附录。
- 重新核价只处理当前询价，保留其他任务价格、用户确认价格与跳过行。
- Agent 内部人民币成本规则增加加急/批量因子，并用测试对照工作台规则；外币、证书、交期和无依据物料仍保留原 MVP 人工核验边界。

## 数据与启动

合并版使用最新压缩包库存数据库的独立副本；不合并其他版本数据库中的处理日志。浏览器5176端口具有独立本地存储，5175端口的用户定价、会话和核对记录不会自动迁入。模型配置沿用当前版本机 `.env.local`，不把压缩包中的密钥配置覆盖进来。

Node.js 22：在 app 下分别运行 `node server/index.mjs` 和 `node node_modules/vite/bin/vite.js`，端口分别为3004和5176。前后端绑定127.0.0.1。

## 验证

TypeScript、Vite构建、Agent工具链测试、对话UI行为测试、报价导出测试、工作台数据验证及新增 `test-merged-workbench.mjs`。新增测试验证加急与批量四种组合的Agent/工作台价格一致；重新核价保留其他任务及手工价格；非法价格阻止导出；跳过行不进入整单金额。

旧 `verify-agent-lifecycle.mjs` 原来依赖固定工作流的批准按钮，合并版改为调用实际连续对话组件的生命周期回归；旧实现仍在最新压缩包解压目录可追溯。
