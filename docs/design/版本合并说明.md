# 工作台与嵌入式助手合并说明

日期：2026-11-05；合并目录 `版本对比/merged-workbench`，分支 `merged-workbench`。来源是 `current-chat` 当时的工作区改动与 `latest-team-20261105/app` 原始解压源码。两个来源均未覆盖，也未自动提交。

## 保留与取舍

- 最新工作台：异常巡检、任务耗时与操作统计、历史快照、重新核价、手工价格保护、暂不报价及客户版待报价清单。
- 最新业务配置：加急溢价、批量折扣、多币种汇率、最低运费与免运费门槛、导入映射与行业配置。
- 当前 Agent：服务端 createAgent、连续对话、整单/行级隔离、取消与迟到保护、嵌入右侧助手及右下角入口。
- 旧工作流 Agent 页面被连续对话助手替代。接受建议单价仅修改当前行价格并记为用户确认价，不自动核销风险。
- 暂不报价的行从 Agent 输入、工作台金额、毛利和客户报价主表排除；客户导出仍按原设计列入待报价附录。
- 重新核价只处理当前询价，保留其他任务价格、用户确认价格与跳过行。
- Agent 内部人民币成本规则增加加急/批量因子，并用测试对照工作台规则；外币、证书、交期和无依据物料仍保留原 MVP 人工核验边界。

## 数据与启动

合并版使用最新压缩包库存数据库的独立副本；不合并其他版本数据库中的处理日志。浏览器5176端口具有独立本地存储，5175端口的用户定价、会话和核对记录不会自动迁入。模型配置沿用当前版本机 `.env.local`，不把压缩包中的密钥配置覆盖进来。

Node.js 22：在 app 下分别运行 `node server/index.mjs` 和 `node node_modules/vite/bin/vite.js`，端口分别为3004和5176。前后端绑定127.0.0.1。

## 验证

TypeScript、Vite构建、Agent工具链测试、对话UI行为测试、报价导出测试、工作台数据验证及新增 `test-merged-workbench.mjs`。新增测试验证加急与批量四种组合的Agent/工作台价格一致；重新核价保留其他任务及手工价格；非法价格阻止导出；跳过行不进入整单金额。

旧 `verify-agent-lifecycle.mjs` 原来依赖固定工作流的批准按钮，合并版改为调用实际连续对话组件的生命周期回归；旧实现仍在最新压缩包解压目录可追溯。

浏览器实测：异常巡检可打开；单行Agent真实模型执行成功；接受208.43元建议价可回填表格，重新核价后该用户确认价保留。测试使用合并版独立存储和演示询价，不涉及对外发送。

## 2026-11-11 团队账户与字段版本合并

本次以 184eca2 版本及当前工作区为基础，合入队员提供的 zidongbaojia.7z 中的实际源码差异。保留现有宣传页工作区内容，压缩包内依赖、构建产物、数据库、账户凭据和编辑器配置均不作为源码合并。

字段定义覆盖询价、库存与供应商报价，支持行业模板、自定义字段、导入映射、提取校验和导出列配置。报价 Agent 接收服务端物料行中的 customFields，客户端伪造值由服务器原始记录覆盖。航空项目使用航空备件模板配置件状、证书及追溯要求。

账户模块加入总账户与子账户、询价归属、认领与指派、禁用和密码重置。首次迁移为现有数据添加账户归属，存量数据归初始总账户。工作台启用应用内登录，初始管理员首次登录需要改密。首次启动可通过 RFQ_BOOTSTRAP_PASSWORD 指定初始密码，未指定时生成随机密码并写入数据库同目录的 .bootstrap.json，权限为 0600。账户配置、MCP 配置及初始化凭据文件同时从 Git 与 Docker 构建上下文排除。

浏览器聊天、引用草稿、字段配置、导入映射、模型配置、报价保存日志、企业资料和签名缓存增加账户命名空间。登录账户使用独立缓存，旧匿名浏览器记录仍保留在原位置。

MCP 提供查询工具与需要用户确认的操作建议。邮箱绑定保存地址与用途，自动邮件收发连接器仍待实现。

合并后的 35 组离线验收脚本、TypeScript/Vite 构建及 /quanta-rfq/ 子路径生产启动检查通过。回归覆盖账户切换的聊天隔离、Agent 自定义字段、同件号分账户库存和单位换算，以及指派后重新匹配新账户依据。真实扫描件 OCR、真实模型供应商调用与线上部署需分别验证。

Claude 独立复核发现的待认领询价依据越权、指派后旧依据残留、处理记录与运行记录查询越权、库存和单位换算主键冲突已修正。记录表增加账户归属，库存与换算采用账户联合主键。初始化凭据复用处理支持迁移失败后的重试。

账户接口回归显式使用隔离的测试模型配置。调试该回归时曾有两次 Agent 运行使用本机已配置模型，其 HTTP 返回状态未用作六阶段业务闭环通过的依据。后续离线验收已强制隔离模型配置。

登录接入后的原件下载通过带认证头的请求获取 Blob；图片与 PDF 预览同样带认证信息。下载链接与预览地址不携带会话令牌。相关回归覆盖受保护原件下载、子路径与真实 DOM 布局。
