审计边界

agent_events 的 UPDATE/DELETE 被 SQL trigger 阻止；registry 不可改删，终态 run 不可更新。这是本地单进程的应用与数据库约束，不等于管理员无法修改数据库或合规防篡改存证。

输入、成本与结果 fingerprint 是指纹，不保存完整成本原始快照；仅靠它们不能重放历史报价。content_sha256 也不等于签名或可信时间戳。
